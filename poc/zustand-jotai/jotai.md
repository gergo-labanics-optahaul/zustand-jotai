# Client-Side Statemanagement

## Jotai

### Introduction
Primitive and flexible state management.
- Extremely fine-grained re-renders (atoms)
- Supports primitives and objects

### Core
- useAtom
- Store (isolate atoms)
- Provider (inject store)

### Utilities
- Storage
- SSR
- Async
- Lazy
- Resettable
- Family

### Extensions
- Effect (Observer)
- Query
- XState (state machine)
- Immer (perform immutable updates)
- Location (links to window.location)
- Cache
- Optics (focuses on specified part of the atom)

### Third-party
- History
- Derive
- Bunja
